# OmniCut Media

Story-driven scroll website for OmniCut Media (founder: Adrian Laas, Australia).
Websites · Technical support · Social media content. Contact via WhatsApp +61 451 335 143.

## Run
Open `index.html`, or serve the folder: `python3 -m http.server` then visit http://localhost:8000

## Notes
- Built with GSAP + ScrollTrigger + SplitText and Lenis (bundled in `assets/js`).
- Stock footage is loaded from Mixkit (free licence) by clip ID: see `data-stock` attributes in `index.html`. Replace with local files in `assets/videos/` if preferred.
- `assets/videos/work*.mp4` are sample clips (tap for sound).
